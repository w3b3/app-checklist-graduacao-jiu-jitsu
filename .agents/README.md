# Antigravity Workspace Customizations (.agents)

This directory contains workspace-level customizations for the Antigravity / Gemini agent tailored to the BJJ Belt Progression Checklist app.

## Contents

- **`rules/`**: Specialized guidelines and constraints for the codebase.
  - [`react-native.md`](file:///Users/ds/dev/repos/checklist_graduacao/.agents/rules/react-native.md): Expo SDK 54, React Native Reanimated 3 plugin order, tablet layout, and styling conventions.
  - [`state-management.md`](file:///Users/ds/dev/repos/checklist_graduacao/.agents/rules/state-management.md): Zustand store patterns, AsyncStorage persistence, and Set serialization requirements.
  - [`release-management.md`](file:///Users/ds/dev/repos/checklist_graduacao/.agents/rules/release-management.md): Version increment rules in `app.json`, EAS build profiles, and store submission blockers.
- **`skills/`**: On-demand procedural runbooks.
  - [`publish-app`](file:///Users/ds/dev/repos/checklist_graduacao/.agents/skills/publish-app/SKILL.md): Step-by-step app store build, version check, and submission workflow.
  - [`add-technique`](file:///Users/ds/dev/repos/checklist_graduacao/.agents/skills/add-technique/SKILL.md): Standard procedure for adding or modifying belt techniques and requirements.
